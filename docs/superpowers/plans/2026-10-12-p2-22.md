## Architecture / pre-flight

Discovery owns only management observations. FFmpeg owns session-scoped decoded
input and output-submission observations. Coordinator policy joins those signals;
OS exit is definitive, warnings/heartbeat/management alone are not media failure.
P2-20/21 still own warning deduplication/latch cleanup and duplicate policy;
P2-24 owns declared track intent/reclassification. P2-22 provides their shared
evidence and destructive-action gate first, not another warning-based shortcut.

FFmpeg's documented per-frame stats can expose decoder-frame index/input PTS and
separate pre-mux packet submission. Input audio frame/PTS advancement must not be
mislabeled as an exact decoded PCM sample count: `sn`/`samp` are encoder-side
samples, after filtering. Missing decoder metadata (`ni=-1`, unknown PTS) stays
Unknown. Exact custom-build propagation through filters remains qualification.
Reference: https://ffmpeg.org/ffmpeg.html#Advanced-options (stats_enc_pre_fmt).

  real audio with synthetic video; digital silence; absent input audio while
  synthetic output counters advance; missing/invalid metadata -> Unknown.
- One media signal fails without corroboration -> retain owner. Two independent
  media signals fail for confirmation window -> one recovery, even when held.
