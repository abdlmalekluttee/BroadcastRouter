# P2-30 — isolated output ownership

This is a software qualification change, not a production deployment. The owner
merges the PR. Hardware qualification and the remaining Phase D tasks are separate.

## Causes addressed

- Changing media-tool settings replaced and synchronously disposed the shared
  supervisor. That could interrupt outputs unrelated to the requested change.
- Serialization was keyed only by source identity, allowing different sources to
  attempt ownership of the same physical output concurrently.
- Shutdown could dispose containment while a native launch was still publishing
  its process, and a busy controller could prevent job cleanup.
- Startup error cleanup used an unbounded synchronous process-exit wait.
- A control-loop watchdog escalated a routing stall to whole-host termination,
  which also terminated healthy owned children.

## New contract

One controller per stable physical output stores its reservation and exact process
session. Source-level serialization also remains for moves between outputs. Only
controller intents execute launch, stop and exit cleanup. Settings publish a new
configuration generation for future starts; existing sessions keep their settings
and graceful-stop budget.

Controller admission and execution have bounded waits. Caller cancellation does
not release an operation that is still running. An uncertain owner remains
unavailable and raises an alarm; a replacement writer is not permitted. Safe idle
recovery clears a controller alarm only after work is quiescent and its exact
session has exited. Reservations survive this recovery.

Supervisor shutdown closes admission, waits for admitted launches within a bounded
budget, stops owned children and always closes its own kill-on-close job. Gates are
not disposed underneath outstanding users. Stops also wait for an already admitted
launch and target that exact resulting session, never a later replacement. The
coordinator closes admission before waiting for its producers, including the case
where no supervisor has yet been created. Delayed exact-session exit cleanup retries
controller admission rather than abandoning an otherwise unavailable port.
A native operation that cannot finish
is reported as uncertain rather than treated as successful cleanup.

The watchdog first attempts safe idle-controller recovery, then publishes a sticky
operator alarm and degraded health. It does not terminate the host or restart a
healthy output because the control loop stalled. Logs and telemetry remain bounded
best effort here; the persistence redesign and flush-timeout investigation are P2-31.

## Evidence and limits

Regression tests cover settings-generation preservation, different-source physical
collisions for live/fallback/standby, cancelled uncooperative operations, exact
session recovery, refused shutdown admission, concurrent launch/containment teardown,
healthy output preservation and rendered operator alarms. A static regression also
forbids reintroducing the parameterless synchronous process-exit wait.

`OutputControllerQualificationTests` runs a short fake-child CI exercise. Set
`BROADCASTROUTER_FAKE_QUALIFICATION_SECONDS=3600` only for the separate one-real-hour
qualification; the default short run does not satisfy that acceptance row. It uses
synthetic fixtures with no network or DeckLink access and records duration, rounds,
worker starts, forced stops, pending-launch stops, shutdown races and preservation
of the unrelated physical control session. Different-source live/fallback/standby
requests contend for the same physical key; retained OS process handles detect
overlapping writers, rather than comparing unrelated session GUIDs.

Full final counts, the independent review and long-run results must be recorded in
the PR before it is marked ready. No physical timing, audio-silence, device-driver,
late-track insertion, host-reboot or soak claim follows from these software tests.
R18 actor/reason redaction remains open for Phase G. The separate bench guard must
remain effective across configuration generations when its PR is integrated.
