## KnownDefect contract

The seven correctness assertions are tagged `Category=KnownDefect` and `Finding`.
`tests/KnownDefects.json` is the exact identity/message allowlist. CI checks build
success, a fresh results folder, runner exit 1, counters, every test identity,
failure message and the top assertion stack frame. Unexpected pass, compile
failure, crash, missing/duplicate result or unrelated runner error makes CI red.
The pinned xUnit adapter duplicates each failed assertion as an Error RunInfo;
only the exact registered `[xUnit.net hh:mm:ss.ff] <test> [FAIL]` echo is accepted
once. All other run-level diagnostics fail closed. A fixing PR must move its
test to the normal suite and remove the registry entry in the same PR.

Open: R04 (2 assertions), R05, R06, R07, R18 (2 assertions). These are not fixes.

## Clock inventory and boundaries

`SupervisionClock` wraps an injected `TimeProvider`. `Now` is an internal,
UTC-anchored monotonic timeline so existing DateTimeOffset policy signatures
remain unchanged. `UtcNow` is actual wall time for event/audit records. One
service-run instance is shared through DI and explicitly passed to child owners.

Converted consumers: RouterCoordinator (all discovery/retry/readiness/lease,
reference checks, liveness, throttle, CPU and cutover measurements), watchdog,
automatic assignment, device-identity route migration, FFmpeg process/progress/
stderr health, Wowza and simulation observations, database refresh scheduling.
Preview session creation and media validation use injected UTC for metadata.
Fast-supervision PeriodicTimers, coordinator pacing, watchdog/DB scheduling and
resilient-loop retry delays use provider-backed timers with unchanged durations.

`TimeBoundary` prevents run-local values crossing into public/persistent UTC:
snapshot ages/deadlines are projected into the current wall-clock frame; route
history timestamps capture actual persistence-observation UTC; all loaded routes
(including automatic routes) are rebased before policies use them. Source DTOs
are converted on save/load. Snapshot StartedAt is an elapsed-age projection,
not the exact OS process creation instant; P2-03 records that separately.

Remaining ambient uses in the guarded Application/Infrastructure/Web.Services
trees (the test fails if any file's allowed count changes):

| File / expression | Count | Justification |
|---|---:|---|
| SupervisionClock / TimeProvider.System | 1 | Only default provider factory |
| SqliteDataStore / DateTimeOffset.UtcNow | 4 | Durable port/source/log audit times; never recovery intervals |
| OperatorTime / DateTimeOffset.UtcNow | 1 | UI-only relative timestamp formatting |
| DeckLinkSoftwareInformationProvider / DateTimeOffset.UtcNow | 1 | Driver-update cache; not route supervision |

No DateTime.Now/UtcNow, Environment.TickCount/64 or Stopwatch use remains in
supervision decisions. Program's health liveness comparisons use injected Now.
I/O guards intentionally retain real duration timers: FFmpeg quit/reap/drain,
FFprobe timeout/drain, ExternalCommandRunner timeout/drain, Wowza HTTP timeout,
preview pipe teardown, watchdog's final log deadline and coordinator shutdown/
lock acquisition budgets. These bound real external operations and remain
effective even when a test freezes its policy clock; they are not wall-date
comparisons or policy backoff. Their durations are unchanged.

Deterministic ±10-second clock tests are boundary unit tests, **not P2-33's real
host NTP qualification**. Windows wall time was not changed.

## Fault coverage: exact limits

| Acceptance input | Automated foundation | Remaining qualification |
|---|---|---|
| Continuous AV, still/black with audio, audio-only, silence | Existing probe/command/progress tests | Real decoded-media health and zero avoidable restarts in P2-20–24/E |

| DeckLink busy/reference loss | Classifier and reference retry unit cases | Bench device response; no hardware opened |
| Slow DB / concurrent save,reassign,stop | Existing settings/persistence and owned stop/start tests | Slow-DB and combined controller stress matrix in P2-30/31 not implemented here |
| Preview plus host crash / service restart | Existing job containment and persisted route tests | Actual preview/probe containment in P2-32; no reboot test |
| 48–72-hour soak | Fast-forwardable clock foundation only | No soak claimed; later bench gates |

The entire acceptance matrix is **not yet an end-to-end automated suite**. This
is an explicit P2-02 acceptance gap, not a passing substitute made from fixture
metadata. Gate A must not claim otherwise.
